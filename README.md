# NCIC Hacktober Fest 2026
The inaugural NCIC hacktoberfest. Starting on October 1st particpants can for this REPO
to start the project. Presentations of the project will be on Friday October 30th in the office.

# The Project
LeTourneau students everywhere remember Dr. Rouse's student picker. A web application that
loads a class roster and will randomly select a student from the class. Once the student is picked 
three options are shown: Correct, Incorrect, or Absent.

## Requirements
- Classes can be created
- Students can be added to classes
- A class can be selected and the class roster is loaded
- A random student from the selected class is displayed
- The selected student can be marked as getting the question correct, incorrect, or absent

More features are welcome to be added by participants: more features is more better.

# Judging Criteria
Everyone will be judged by their fellow participants. Here are some areas to keep in mind when
judging other projects:
- Is it functional?
- Design
- Tech stack
- Unique solutions

# Docker Nuxt Student Picker
This is my take on the student picker. I wanted something that will be easy to setup and run on day one of Dr. Rouse's class. Docker was the obvious solution.

## Teck Stack
- Docker (version 29.6.2)
  - Devcontainers (0.89.0)
